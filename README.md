# Қазақ CRM

Казақ тілінде Customer Relationship Management (CRM) веб-қосымшасы.

## Ерекшеліктері

- Қолданушы басқарылуы
- Клиент басқарылуы
- Сату басқарылуы
- Іс-әрекеттер
- Ақпараттық тақта

## Технологиялары

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT
